# IMPERIO DA BELEZA

Projeto de apresentação de salão e agendamento de clientes, onde atende 3 profissionais.

## Objetivo
Ele foi criado para suprir a necessidade de ter uma secretária para 3 profissionais, assim, tendo facilidade e eficiência no agendamento e corfirmamento de horario 
e datas disponiveis.

## Tecnologias
- HTML
- CSS
- php
- SQL
  
## Como acessar
O projeto ainda esta em desenvolvimento no Projeto Integrador 2.

## Funcionalidades

Funcionalidades — Império da Beleza
Página pública
- Página inicial do salão com apresentação das profissionais.
- Portfólio de fotos dos trabalhos.
- Botão de WhatsApp por profissional.
- Exibição da localização do salão.
- Navegação entre página inicial, agendamento e painel da profissional.
Cadastro e acesso do cliente
- Cadastro e login do cliente.
- Armazenamento dos dados do cliente no banco de dados.
- Autopreenchimento dos dados do cliente no agendamento.
- Edição dos dados cadastrais do cliente.
- Exclusão do cadastro do cliente.
- Consentimento para uso de dados e aceite da política de privacidade.
Gestão de serviços
- Cadastro de serviços.
- Definição da duração dos serviços.
- Definição dos preços dos serviços.
- Edição de serviços cadastrados.
- Remoção de serviços cadastrados.
Agendamento
- Agendamento público de atendimentos.
- Seleção de profissional, serviço, data e horário.
- Cálculo automático da duração do serviço.
- Verificação de horários disponíveis.
- Validação de conflitos entre agendamentos.
- Salvamento dos agendamentos no banco de dados.
- Confirmação do agendamento para o cliente.
- Consulta de horários disponíveis por profissional.
Painel da profissional
- Login seguro da profissional.
- Acesso individual à agenda de cada profissional.
- Visualização da agenda de atendimentos.
- Busca de clientes por nome ou telefone.
- Filtro de agendamentos por período, status e serviço.
- Painel de indicadores de agendamentos, cancelamentos e atendimentos concluídos.
Gestão da agenda
- Configuração de horários recorrentes por dia da semana.
- Bloqueio de datas específicas para folgas e férias.
- Visualização dos horários disponíveis.
- Confirmação de presença pelo cliente.
- Cancelamento de agendamentos pelo cliente.
- Reagendamento de atendimentos pelo cliente.
- Registro do status dos agendamentos.
- Histórico de cancelamentos sem apagar os registros anteriores.
- Tela de consulta dos agendamentos do cliente.
Lembretes e notificações
- Lembretes de atendimento com 24 horas de antecedência.
- Lembretes de atendimento com 2 horas de antecedência.
- Exibição dos lembretes no sistema.
Gestão de atendimentos
- Registro de atendimento concluído.
- Histórico de atendimentos por cliente.
- Registro de anotações da profissional sobre os atendimentos.
- Registro de produtos utilizados e preferências da cliente.
- Avaliação do atendimento pelo cliente com nota de 1 a 5.
Gestão do portfólio
- Upload de imagens do portfólio.
- Validação do tipo e tamanho dos arquivos enviados.
- Gerenciamento das imagens do portfólio.
- Exibição do portfólio por profissional.
- Exibição do portfólio por serviço.
Gestão financeira
- Relatório financeiro simples por profissional.
- Visualização dos ganhos provenientes dos atendimentos.
Privacidade e proteção de dados
- Registro do consentimento para uso de dados pessoais.
- Registro da data e hora do aceite da política de privacidade.
- Solicitação de exclusão dos dados pessoais do cliente.
- Anonimização dos dados pessoais, inclusive nos agendamentos antigos.
